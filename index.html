Introduktion till Python och analys och modellering av grundvattentidsserier

This documentation explains how to install Python, verify the installation, run Python code, and create isolated virtual environments. All of which needs to be completed before starting the course.

Tip

You find general course information, e.g. schedule, in the About section.

Introduction

Before starting the course, make sure that you have installed Python and the required packages. You can follow the instructions in the Installing Python section to install Python and the required packages. After installation, you can verify that everything is working correctly by following the steps in the Jupyter Notebooks section.

Note

If you need any help or have any questions, please contact the course responsible or the course instructors. We are happy to help you get started with Python and the course.

Erik Toller erik.toller@wsp.com

IDE

An IDE (Integrated Development Environment) is a software application that provides comprehensive tools for software development. It typically includes a source code editor, build automation tools, and a debugger. There are many IDEs available for Python, and this course does not require the use of a specific one.

The course materials and exercises are provided as Jupyter Notebooks, and we, the instructors, will use Jupyter Lab.

Warning

Many companies have strict policies regarding the installation of software on work computers. If you are using a work computer, please check with your IT department before installing any software. You may need to use an approved installation method or install into your user profile if organizational policy permits it.
